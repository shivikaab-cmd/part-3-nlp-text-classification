## Project Overview

This project demonstrates Natural Language Processing (NLP) techniques for customer support text classification.

The notebook performs:
- Text preprocessing
- TF-IDF vectorization
- Baseline Logistic Regression model
- Deep Learning using LSTM
- Confusion matrix generation
- Accuracy visualization

---

## Dataset

Dataset used:
- customer_support_text_classification.csv

The dataset contains customer support messages categorized into sentiment classes.
